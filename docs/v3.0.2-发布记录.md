# v3.0.2 发布记录

> 日期：2026-05-29
> 主题：修复 macOS「没有执行权限」的问题

## 背景

在 macOS 上双击运行脚本时，如果脚本文件丢了「可执行」权限（常见于从压缩包解压、网络下载、或某些方式拷贝之后），系统会报「没有执行权限」，用户得先手动在终端跑一次 `chmod +x` 才能用，门槛偏高。

## 修复

让 macOS 的两个入口脚本在启动时**自动给自己赋予执行权限**，双击即可运行，无需手动处理。脚本开头新增：

```bash
chmod +x "$0" >/dev/null 2>&1 || true
```

（`|| true` 兜底：即便赋权失败也不会中断脚本。）
