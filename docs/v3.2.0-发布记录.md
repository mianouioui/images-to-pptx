# v3.2.0 发布记录

> 日期：2026-05-31
> 主题：无编号图片回退按文件修改时间排序 + README 三语化

## 背景

此前工具严格要求图片文件名末尾包含两位及以上数字（如 `page001.jpg`），不符合该规则的图片会被跳过。用户若有未按编号命名的图片集（例如从相机导出的 `IMG_0001.jpg` 或完全没有数字编号的文件），必须事先重命名才能使用。这对临时图片集或批量素材很不友好。

本版新增回退排序：当文件夹内完全没有符合编号规则的图片时，三套实现会自动切换为按文件修改时间（mtime）升序排列，最旧的文件排在最前面。用户无需重命名文件即可直接生成 PPTX。

同时 README 补齐法语版本（Documentation française），与中文说明、English Documentation 形成三语对称结构。

## 改动

1. **无编号图片按文件修改时间回退排序**：
   - Python：`find_images()` 在 `images` 列表为空但 `skipped_unnumbered` 非空时，用 `path.stat().st_mtime` 升序排列，依次分配编号 001、002、……
   - macOS zsh：`scan_images()` 在 `numbers` 数组为空时，用 zsh glob 限定符 `(.Nom)` 按 mtime 升序重新收集所有 JPG/PNG，按序分配编号。
   - Windows PowerShell：`Scan-Images` 在 `$numbers` 为空时，用 `Sort-Object LastWriteTime` 升序重新收集所有 JPG/PNG，按序分配编号。
2. **交互模式校验放宽**：
   - Python：`has_numbered_images()` 替换为 `has_any_images()`，只要有 JPG/PNG 图片即可接受。
   - macOS / Windows：`prompt_input_dir` / `Read-InteractiveInputDir` 错误提示更新为「这个文件夹里没有 JPG/PNG 图片」。
3. **互动横幅文案更新**：三套实现的横幅将「只挑文件名末尾 2 位及以上数字」改为「优先按文件名末尾数字排序」，并补充回退说明。
4. **README 新增法语版本**：在 English Documentation 之后追加完整 Documentation française，章节结构与中英文完全对称；顶部导航新增法语链接。
5. **版本号**：三套入口统一 bump 至 3.2.0；文件头部注释、`$Version` 变量、`__version__` 同步更新。

## 兼容性说明

- 已有编号规则的图片集行为完全不变：依然按末尾数字的数值大小排序。
- 回退排序仅在**完全没有**符合编号规则的图片时触发；若文件夹中同时存在部分编号图片和部分无编号图片，编号图片优先使用（无编号图片仍被跳过）。
- `--strict` 在回退场景下自动通过（回退分配的编号是连续的 1, 2, 3, …）。
- README 三语版本均独立完整，法语版本不影响中英文内容。
