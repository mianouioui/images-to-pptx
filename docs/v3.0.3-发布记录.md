# v3.0.3 发布记录

> 日期：2026-05-30
> 主题：macOS 脚本重命名对称化 + 删除冗余入口

## 背景

此前 macOS 侧有两个文件：实现脚本 `图片转PPTX.command`，以及一个 5 行的入口壳脚本 `run_macos.command`（仅 `exec` 转发到前者）。同时 macOS 实现脚本名缺少平台后缀，与 Windows 版 `图片转PPTX-Windows.cmd` 不对称。

## 改动

1. **重命名**：`图片转PPTX.command` → `图片转PPTX-macOS.command`，与 `图片转PPTX-Windows.cmd` 对齐，文件名直接标明平台（大小写采用标准的 `macOS`）。
2. **删除** `run_macos.command`：全仓搜索确认它无任何文件/代码引用，功能完全被实现脚本覆盖；macOS 用户直接双击 `图片转PPTX-macOS.command` 即可，与 Windows 用法一致。

## 本次改动的文件

- `图片转PPTX.command` → `图片转PPTX-macOS.command`：重命名；脚本内写入 PPTX 元数据的 `<Application>`／`<dc:creator>`／`<cp:lastModifiedBy>` 三个字段同步改为新文件名；版本号注释 → 3.0.3
- `run_macos.command`：删除
- `图片转PPTX-Windows.cmd`：版本号注释 → 3.0.3（仅同步版本号，逻辑未动）
- `images_to_pptx.py`：版本号 `__version__` → 3.0.3（仅同步版本号，逻辑未动）

随附文档更新：

- `CHANGELOG.md`：新增 `[3.0.3]` 条目。
- `README.md`：macOS 用法/说明里的脚本名改为 `图片转PPTX-macOS.command`（3 处）。

## 兼容性说明

- macOS 用户若此前固定双击 `run_macos.command`，改双击 `图片转PPTX-macOS.command` 即可。
- 旧版发布记录（`docs/v3.0.1-发布记录.md`、`docs/v3.0.2-发布记录.md`）与 `CHANGELOG.md` 历史条目中出现的旧文件名属历史快照，未改动。

## 验证

- `图片转PPTX-macOS.command`：`zsh -n` 语法检查通过；可执行权限位保留。
- `images_to_pptx.py`：`python3 -m py_compile` 通过（仅改版本号字符串）。
- `图片转PPTX-Windows.cmd`：仅改版本号注释，逻辑未动（开发机无 PowerShell，未实跑）。
- 活跃文件（脚本 / README）已无 `run_macos` 与旧 macOS 文件名残留引用。
